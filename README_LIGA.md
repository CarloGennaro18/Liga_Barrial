# ⚽ Liga Barrial API — Proyecto Integrador Tecnologías Web 1

Backend REST en **NestJS + TypeScript** para administrar una liga barrial de fútbol:
equipos, jugadores, árbitros, canchas, partidos, resultados, tarjetas/sanciones
y **tabla de posiciones calculada automáticamente**.

## Stack
- Node.js (v20+)
- TypeScript
- NestJS
- class-validator + class-transformer (DTOs y validaciones)

> No usa base de datos (los datos viven en memoria), conforme al alcance hasta la semana 8.

## Requisitos
- Node.js >= 20
- npm
